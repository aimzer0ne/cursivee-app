Why fancy text shows up as boxes or question marks

Empty boxes, question marks and letters that quietly turn plain again are three different problems with three different causes. Here is how to tell which one you have.

The short answer

An empty box means the device you are looking at has no font that can draw that character. The text itself is intact: copy the box, paste it somewhere with better fonts, and the letter reappears. The fix is on the viewing device, not in the text.

That is the common case, but it is not the only one. What you see tells you what went wrong.

Empty boxes: a missing font

Text is stored as numbers. Every character has one, fixed by the Unicode standard. To put a character on screen, your device looks up that number in a font, which holds the drawing. No font covers everything, so the system keeps a list of fallbacks and tries each in turn. When it runs out, it draws a placeholder box. Typographers call that box tofu, and Google's Noto font family takes its name from the aim of eliminating it: "no tofu".

So a box is not an error in your text. It is a device admitting it does not know what that character looks like. Two people can look at the same bio and one sees cursive while the other sees a row of rectangles.

Question marks: damaged text

A question mark or a black diamond with a question mark inside it (�) means the character was lost before it reached the screen. This happens when text passes through something that cannot store the full Unicode range: an old database, an SMS gateway, a form that predates emoji, a file saved in a legacy encoding. Once it is replaced, no font will bring it back. Paste the original again, somewhere else.

Plain letters: the platform said no

Some fields run your text through a clean-up step when you save. Usernames are the usual example. Platforms do this on purpose, because lookalike characters make it easy to impersonate another account. If your script letters come back as ordinary ones, or the field refuses to save, that field does not allow them. Use the bio or display name instead; this guide lists which fields accept what.

Which styles are most likely to break

The older a character set is, the more devices can draw it. This is a rough guide to how much risk each style carries.

One oddity in the filled squares: some platforms draw 🅰, 🅱, 🅾 and 🅿 as coloured emoji buttons while leaving the other letters as plain black squares. A word containing those four letters can come out looking patchy. If that matters, pick a different style.

How to fix it

If the boxes are on your own device

  • Update the operating system. Font coverage arrives with system updates, and this fixes most cases on phones.
  • On a computer, install a font that covers the range. Noto Sans Math and STIX Two Math are both free and include the mathematical alphabets that script and blackletter styles use.
  • Try a different app. Games, terminals, streaming overlays and some chat clients ship their own narrow fonts and ignore the system ones. The same text may display perfectly in a browser.

If the boxes are on someone else's device

You cannot install a font on another person's phone. What you can do is choose characters they are more likely to have. Move up the table: bold script in place of squares, bubbles in place of filled bubbles. And keep fancy text to short decorative phrases, so that a reader who gets boxes loses a flourish rather than your name.

A thirty-second test before you commit

  1. Paste the text where you intend to use it and save.
  2. Reload the page. Some platforms show your original until a refresh reveals what was really stored.
  3. Open it on a second device, ideally a different kind: Android if you use an iPhone, a laptop if you use a phone.
  4. If you can, look at it logged out. That is what everyone else sees.

If it survives all four, it will survive for nearly everyone. The generator shows every style side by side, so swapping in a safer one takes a few seconds.
